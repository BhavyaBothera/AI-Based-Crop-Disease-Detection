🔬 How PHYTOSIGNAL Works

🌿 1. Foliar Input Standardization

The platform ingests JPEG, PNG, and WebP foliar images up to 10 MB and 20 megapixels. The input image is preprocessed deterministically: bounded memory allocation, decompression bomb safeguards, aspect-ratio preservation, and normalization to 224×224 RGB tensors.

⚡ 2. MobileNetV2 Neural Feature Extraction

A class-weighted MobileNetV2 architecture with depthwise separable convolutions analyzes hierarchical lesion features (chlorosis, necrotic spots, concentric rings, pustules, vascular browning). Inference executes with sub-100ms latency on CPU, generating distribution scores across 15 trained Solanaceae classes.

⚖️ 3. Closed-World Softmax Distribution

Output scores represent relative softmax distribution across the 15 registered classes under closed-world assumptions. They do not constitute calibrated statistical certainties. The top-3 candidate classes are always surfaced to ensure diagnostic transparency.

📋 4. Grounded IPM Knowledge Base Integration

Each condition is linked to peer-reviewed Integrated Pest Management (IPM) protocols. The system provides causal pathogen taxonomy, foliar symptom summaries, environmental transmission factors, non-chemical & cultural controls, and cautious chemical principles.

Advisory Limitation: PHYTOSIGNAL is an automated foliar screening assistant, not a definitive agronomic laboratory diagnosis. Always consult certified agricultural extension specialists before applying pesticide interventions.
